# ProntoTest · Guide

Статическая вёрстка раздела «Guide» сайта ProntoTest: страница листинга советов и
страница статьи. Макет — `Pronto.pen` (pen.dev), спецификация — `Pronto-Guide-Spec.md`.

## Что внутри

```
index.html              листинг советов (bento-сетка из 11 плиток)
article.html            страница статьи
assets/css/styles.css   токены, сетка, типографика, состояния и анимации
assets/js/app.js        sticky-шапка, появление плиток, чипы, бургер-меню, copy link
assets/icons.svg        SVG-спрайт иконок, выгружен из макета
assets/fonts/           M PLUS U (variable, latin-subset) и Geist (variable)
assets/images/          иллюстрации советов и бейджи сторов
```

## Соответствие макету

Все значения — цвета, радиусы, отступы, кегли, интерлиньяж, трекинг — перенесены
из `Pronto.pen` без округлений. Токены собраны в `:root`.

| Вьюпорт | Контейнер | Боковые поля |
|---|---|---|
| 390 | 342 | 24 |
| 1280 | 1200 | 40 |
| 1440 | 1200 | 120 |
| 1920 | 1200 | 360 |

Между 768 и 1279 работает десктопная логика: контейнер `100% − 80px`, сетка плиток
переходит в две колонки ниже 1100. Ниже 768 включается мобильный макет: шапка 56,
лента чипов с прокруткой, плитки в один столбец, скругление 24.

Анимации построены только на `transform` и `opacity`, при `prefers-reduced-motion`
остаются переходы прозрачности.

## Разработка

Сборки не требуется — это статические файлы. Страницы собираются скриптом
`src/build.py` (общие шапка, футер и меню), локально достаточно любого статического
сервера:

```bash
python3 -m http.server 8000
```

## Шрифты

- **M PLUS U** — заголовки. Переменный, подмножество latin, 36 КБ.
- **Geist** — весь остальной текст. Переменный, npm-пакет `geist`.

Оба шрифта лежат в репозитории и подключены через `@font-face` с `font-display: swap`.
