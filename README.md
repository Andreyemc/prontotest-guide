# ProntoTest · Guide

Раздел Guide сайта ProntoTest: хаб со списком советов и 20 страниц статей.
Дизайн — `Pronto.pen` (pen.dev) и `Pronto-Guide-Spec.md`, контент — `ProntoTest-Guia-spec.md`.

Прод: https://prontotest-guide.vercel.app

## Структура

```
index.html              хаб: bento-сетка, фильтр по темам, пагинация по 9
guia/{slug}.html        20 статей по одному шаблону
data/guide.json         контент: тексты, даты, alt, ассеты, связки More tips
src/parse_spec.py       разбор контент-спеки в data/guide.json
src/build.py            генерация хаба и страниц статей
src/icons.py            выгрузка SVG-спрайта иконок из макета
assets/css/styles.css   токены, сетка, типографика, состояния, скелетоны
assets/js/app.js        шапка, появление, фильтр, пагинация, меню, share, иконки
assets/icons.svg        спрайт иконок категорий (Iconoteka, из макета)
assets/fonts/           M PLUS U (latin-subset) и Geist, оба variable
assets/images/badges/   официальные бейджи App Store и Google Play
```

Сборки нет, это статические файлы. После правки данных или шаблонов:

```bash
python3 src/parse_spec.py путь/к/ProntoTest-Guia-spec.md data/guide.json
python3 src/build.py
python3 -m http.server 8000
```

## Соответствие макету

Цвета, радиусы, отступы, кегли, интерлиньяж и трекинг перенесены из `Pronto.pen`
без округлений; токены собраны в `:root`.

| Вьюпорт | Контейнер | Боковые поля |
|---|---|---|
| 390 | 342 | 24 |
| 1280 | 1200 | 40 |
| 1440 | 1200 | 120 |
| 1920 | 1200 | 360 |

Между 768 и 1279 работает десктопная логика с контейнером `100% − 80px`, сетка
плиток переходит в две колонки ниже 1100. Ниже 768 включается мобильный макет.

Раскладка bento повторяет макет: ряд из двух больших плиток, ряд из трёх малых,
фича во всю ширину, ещё ряд из трёх малых — ровно девять карточек на страницу.
Вид плитки задаётся позицией, а не статьёй, поэтому сетка остаётся целой и при
фильтрации, и на последней странице с двумя карточками.

## Ассеты статей

Анимации (SVG 1200×675, CSS-кейфреймы) и обложки (WebP) подключены по прямым
ссылкам на `storage.prontotest.net` — так разрешает контент-спека. Чтобы
положить их в репозиторий, нужно скачать по URL из `data/guide.json` в
`assets/images/guia/` и заменить поля `animation` и `cover` на локальные пути.

## Шрифты и иконки

- **M PLUS U** — заголовки. Variable, подмножество latin, 36 КБ.
- **Geist** — остальной текст. Variable, npm-пакет `geist`.
- Иконки категорий — спрайт из макета.
- Анимированные иконки интерфейса — [useAnimations](https://useanimations.com)
  (MIT). Lottie-плеер и файлы иконок грузятся лениво и только если в системе не
  включено «уменьшить движение»; до этого работают статичные SVG.

## Поведение

- Фильтр по темам и пагинация по 9 карточек, страницы пересобираются на лету.
- Скелетоны первого экрана: появляются, только если контент не пришёл за 120 мс,
  держатся минимум 300 мс, гаснут за 150 мс, дальше каскад появления.
- Share через Web Share API, Copy link через буфер обмена; в шаринг уходит
  канонический URL на `prontotest.net`, а не адрес стенда.
- Все переходы на `transform` и `opacity`; при `prefers-reduced-motion`
  остаются только изменения прозрачности.

## SEO

canonical и hreflang (es / en / ru / x-default) ведут на `prontotest.net`,
Open Graph и Twitter-карточки заполнены, JSON-LD `@graph` содержит Organization,
BreadcrumbList, ImageObject и Article. Стенд закрыт `robots: noindex,follow` —
снять при переносе на боевой домен.
